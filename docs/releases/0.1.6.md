# Quiet Bar 0.1.6

시계 클릭으로 알림 센터를 열고, 창이 열린 상태에서 기존 아이콘 숨김을 다시 적용하도록 개선했습니다.

- 메뉴 막대가 접힌 상태에서 시계를 클릭해도 알림 센터가 열리지 않던 문제를 수정했습니다.
- 알림 센터가 열리면 기존 숨김·항상 숨김 구역과 접힘·일반 펼치기 상태를 바로 적용합니다.
- 열기 처리 중 전체 복원이나 설정을 선택한 경우 해당 조작을 우선합니다.

알림 센터를 여는 짧은 동안에는 숨김 아이콘이 잠시 표시될 수 있습니다. 빌드 9 설치본에서 알림 센터가 유지되면서 아이콘은 다시 접히는 기본 동작을 확인했습니다.
