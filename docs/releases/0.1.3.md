# Quiet Bar 0.1.3

메뉴 막대의 아이콘을 위치에 따라 정리하는 Quiet Bar의 초기 기능과 0.1.1–0.1.3 개선 사항을 담았습니다.

## 0.1.0 — 기본 기능

- 구분선 위치에 따라 아이콘을 숨김·항상 숨김·표시 구역으로 관리합니다.
- 메뉴 막대 화살표로 숨김 구역을 접고 펼칩니다.
- 로그인 시 실행, 시작할 때 설정 표시, 자동 숨김, 전역 단축키를 제공합니다.
- macOS 27의 메뉴 막대 환경에 대응하고, 오류가 발생하면 아이콘을 다시 표시합니다.

## 0.1.1 — 위치와 권한 처리 개선

- 여러 디스플레이에서 구분선 위치를 읽는 방식을 개선했습니다.
- 권한 상태 확인과 권한 재등록 안내를 보완했습니다.

## 0.1.2 — 구분선 표시 개선

- 메뉴 막대를 접으면 일반 구분선과 항상 숨김 구분선도 함께 숨깁니다.
- 펼치거나 배치를 편집하면 구분선을 원래 위치에 다시 표시합니다.

## 0.1.3 — 배치 자동 반영과 한글 설정

- ⌘ 키를 누르고 아이콘을 옮긴 뒤 키와 마우스를 놓으면 배치를 자동으로 반영합니다.
- 일반 구분선 안쪽으로 옮긴 앱은 숨김 대상에 포함하고, 바깥쪽으로 빼면 제외합니다. 대상이 바뀌면 별도 버튼 없이 접습니다.
- 일반 구역을 펼친 상태에서 배치를 바꿔도 기존 항상 숨김 대상은 유지합니다.
- 설정을 간결한 한국어 일반·정보 탭으로 정리했습니다.
- 펼칠 때 메뉴 막대 공간을 확보하는 옵션을 추가했습니다.
- 정보 탭에 웹사이트, GitHub, 이메일 링크를 정리하고 진단 정보는 별도 메뉴로 옮겼습니다.
