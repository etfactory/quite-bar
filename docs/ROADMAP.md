# 기능 범위와 후속 작업

## 0.1.0에 포함

- SwiftUI 한국어 설정, AppKit 메뉴 막대 세 항목.
- ⌘-드래그 위치로 숨김 범위 결정.
- 선택적인 항상 숨김 구역, 자동 숨김, 전역 단축키, 로그인 실행.
- macOS 27 네이티브 제한 엔진과 이전 OS 길이 확장 엔진.
- 오류·취소·환경 변화 시 복원.
- 외부 의존성 없는 빌드, 테스트 11개, 개발·호환성 문서.

## 0.1.1–0.1.3에 추가

- 상태 항목 창 기반 다중 화면 좌표, 권한 재등록 절차.
- 접기 때 두 구분선 숨김, 펼치기·복원 때 위치를 보존하며 표시.
- ⌘-드래그 후 일반 숨김 대상 자동 갱신, 일반 펼치기 중 기존 항상 숨김 유지.
- 간결한 한국어 설정·정보 탭과 별도 지원 진단 메뉴.
- 펼칠 때 Quiet Bar의 짧은 앱 메뉴로 공간을 확보하는 선택 기능.

## 다음 검증

1. 응용 프로그램 폴더 설치 후 AX 허용 상태에서 실제 접기·펼치기 확인 — 0.1.1에서 이 Mac의 기본 경로 완료.
2. 알림 센터·제어 센터·개인정보 지시 표시가 유지되는지 확인.
3. 다중 디스플레이, 노치, 전체 화면, 메뉴 막대 자동 숨김 확인.
4. 로그인 항목·단축키 충돌·권한 철회 확인.
5. macOS 13–26 호환 장치에서 길이 확장 엔진 확인.

구체적인 체크리스트와 완료 상태는 [TESTING.md](TESTING.md)를 기준으로 유지합니다.

## 아직 구현하지 않은 것

- 노치·공간 부족 아이콘을 표시하는 별도 오버플로 행.
- 동일 앱의 개별 아이콘별 숨김 규칙.
- 화면마다 다른 분류와 프로필.
- 마우스 올리기만으로 펼치기.
- 다른 앱의 열린 메뉴를 추적해 자동 숨김을 완전히 억제하기.
- 다국어 번역, 업데이트 서비스, Developer ID 공증 및 배포 자동화.

별도 오버플로 행은 아이콘 표시뿐 아니라 원본 클릭 전달, 권한, 다중 화면 좌표 처리가 필요하므로 후속 범위로 남깁니다. 공개 API만으로 안정적인 제어가 가능해지면 비공개 드라이버 교체를 우선합니다.
