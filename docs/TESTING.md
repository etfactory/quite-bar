# 테스트와 검증 기록

## 0.1.3 드래그 자동 반영·설정 정리 — 2026-10-19

드래그 판정 9개와 일반 구역 갱신 9개, 총 18개 코어 테스트를 추가했습니다. 전체 32개가 통과했고 Release 범용 빌드와 설치된 앱의 설정·정보 화면을 확인했습니다. 코어 테스트는 실제 메뉴 막대를 조작하지 않습니다.

| 실행한 항목 | 결과 |
| --- | --- |
| 전체 코어 테스트 | 32개 통과, 실패 0 |
| Release 범용 빌드 | arm64 / x86_64 성공, 최종 컨트롤러 수정 후 재빌드도 통과 |
| 설치된 앱의 일반 탭 | 한국어 체크박스 5개·전역 단축키·시간 선택 팝업을 화면과 Accessibility 트리로 확인 |
| 설치된 앱의 정보 탭 | 앱 이름·버전과 웹사이트·GitHub·이메일 링크 3개를 화면과 Accessibility 트리로 확인, SNS·기술 본문 제거 확인 |

검증 후 앱은 전체 표시·배치 편집 상태로 두었습니다. 기존 사용자 설정값을 유지했고 새 전체 메뉴 막대 옵션은 기본 꺼짐입니다. 다른 앱의 권한은 변경하지 않았습니다.

메뉴 공간 확보 옵션의 포커스 복원·시간 자동 숨김 연계와 숨겨진 진단 메뉴도 아래 수동 확인 계획에 포함합니다. 위 결과표에 없는 항목을 완료한 것으로 보지 않습니다.

| 새 자동 테스트 범위 | 확인하는 동작 |
| --- | --- |
| 드래그 시작 조건 | ⌘ 키·메뉴 막대 위치가 모두 맞을 때만 추적 |
| 최소 이동량 | 4pt 경계 및 이동 없는 클릭 구분 |
| 드래그 종료·취소 | 종료 좌표 반영, 취소와 다음 드래그의 상태 초기화 |
| 일반 구역 이동 | 일반 경계 안으로 넣으면 포함, 밖으로 빼면 제외 |
| 항상 숨김 보존 | AX 누락·오래된 좌표·다른 화면 좌표에도 기존 목록 유지 |
| 기존 분류 정책 | RTL, 같은 앱의 여러 아이콘, 보호 대상·잘못된 프레임·경계 거절 유지 |

## 0.1.2 구분선 숨김 검증 — 2026-10-19

macOS 27.0.1의 `/Applications/Quiet Bar.app`에서 다음을 확인했습니다. 기존 설정값은 유지했고, 검증 후에는 접힌 상태로 두었습니다.

| 실행한 항목 | 결과 |
| --- | --- |
| Release 범용 빌드·서명 | arm64 / x86_64 빌드 및 설치 시 서명 검증 통과 |
| 기존 코어 테스트 | 14개 통과, 실패 0 |
| 항상 숨김 구역이 켜진 상태에서 접기 | 일반·점선 모두 `length=0`, 버튼 이미지 없음; 화살표는 `length=18`, 이미지 표시 |
| 일반 펼치기 | 두 구분선 모두 `length=18`, 이미지 복원 |
| 펼치기 → 접기 → 펼치기 → 접기 반복 | 배치 오류 없이 상태 전환 성공 |
| 접힌 상태에서 배치 편집 → 새 위치 수집 후 다시 접기 | 전체 복원 후 다시 접기 성공, 두 구분선 숨김 |

0폭 상태 항목에도 macOS가 16pt 폭의 호스팅 창을 유지하는 것을 관찰했습니다. 세로 구분선 이미지는 제거되지만 OS 여백까지 없어지는 구현은 아닙니다. 상태 항목을 제거하지 않아 구역 배치를 유지합니다.

아래는 전체 수동 검증 계획입니다. 위 결과표에 없는 오류 주입·적용 도중 취소·앱 재시작·이전 OS 항목은 이번 변경에서 추가로 실행하지 않았습니다.

### 위치 분류 5개

- 세 구역 분류와 같은 앱의 가장 잘 보이는 구역 우선.

- 자기 앱, Apple 앱, 빈 식별자, 잘못된 좌표, 다른 화면·행 보호.

### 세션 수명 6개

- 활성화 실패 시 기존 제한 해제.
- 예전 요청이 최신 결과를 덮어쓰지 못함.
- API 부재 또는 숨김 대상 없음에서 활성화하지 않음.

실행: `./scripts/test.sh`. 제한된 컴파일러 환경에 대한 옵션은 [BUILDING.md](BUILDING.md)를 참고하세요.
