## 0.1.3 — 2026-10-19

검증 환경은 macOS 27.0.1 (26A434), Xcode 27.0, Swift 6.4입니다. 자동 코어 테스트는 실제 메뉴 막대, Accessibility 권한, 문서화되지 않은 시스템 인터페이스를 사용하지 않습니다.

| 확인한 항목 | 결과 |
| --- | --- |
| 코어 테스트 | 32개 통과, 실패 0 |
| Release 범용 빌드 | arm64 / x86_64 성공 |
| 설치본 ad-hoc 서명 검증 | 통과 |
| 설치된 앱의 일반 탭 | 한국어 설정·전역 단축키·시간 선택 UI 확인 |
| 설치된 앱의 정보 탭 | 앱 이름·버전과 웹사이트·GitHub·이메일 링크 3개 확인 |
| 설치본 권한 | 기존 권한 항목 갱신 후 앱의 권한 안내 해제 확인 |

**실제 ⌘-드래그 자동 반영은 미검증입니다.** 마우스 이벤트, 키 해제 대기, 비동기 위치 수집과 제한 적용을 연결하는 전체 경로는 아래 실제 Mac 수동 확인 항목으로 남아 있습니다. 메뉴 공간 확보 옵션의 포커스 복원·자동 숨김 연계와 진단 메뉴도 추가 확인이 필요합니다. 빌드 및 코어 테스트 성공이 해당 통합 동작까지 보증하지 않습니다.

## 이전 버전의 실제 동작 확인

아래는 macOS 27.0.1 설치본에서 수행한 범위입니다. 다른 OS·하드웨어에 대한 결과는 아닙니다.

| 버전 | 확인한 동작 |
| --- | --- |
| 0.1.1 | 권한 재등록 후 GUI 앱의 AX 승인, 위치 수집과 구역 분류, 실제 접기·일반 펼치기·전체 복원 |
| 0.1.2 | 접기 때 일반·점선 이미지 제거와 `length=0`, 화살표 유지, 펼칠 때 두 구분선 복원, 반복 전환, 전체 복원 후 다시 접기 |

0폭 상태 항목에도 macOS가 호스팅 창 여백을 유지하는 것을 관찰했습니다. 구분선 이미지는 제거되지만 OS 여백까지 없어지는 구현은 아닙니다. 상태 항목을 제거하지 않아 배치를 유지합니다.

macOS 13–26에서 길이 확장 엔진의 실제 동작은 아직 검증하지 않았습니다. 로그인 실행, 전역 단축키 충돌, 화면 연결·분리, 노치·전체 화면, 시스템 지시 표시를 포함한 아래 전체 목록도 완료하지 않았습니다.

## 변경 시 확인 기준

위치·구역 정책 변경은 `LayoutTests`와 `DragMembershipTests`, 비동기 수명·실행 앱 갱신 변경은 `VisibilityTests`와 `RunningBundleRefreshTests`를 보강합니다. 타이머·AppKit 상태 항목·Objective-C 브리지 변경은 관련 실제 Mac 확인을 추가합니다. 문구·색상 변경은 빌드와 시각 확인으로 검증합니다.
